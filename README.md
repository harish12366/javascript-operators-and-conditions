# 🟨 JavaScript Operators & Conditions

A beginner-friendly JavaScript practice project focused on **operators, conditional statements, ternary operators, and switch statements**.

---

## 📚 Concepts Covered

- ➕ Arithmetic Operators
- 🔍 Comparison Operators
- 📝 Assignment Operators
- 🧠 Logical Operators
- 🔀 `if`, `else if`, `else`
- ❓ Ternary Operator
- 🔄 `switch` Statement
- 🧮 Calculator Logic
- 🎓 Grade & Result Calculation

---

## 🧮 1. Calculator Logic

A simple calculator program that performs different operations based on the selected operator.

### Supported Operations

| Operator | Operation |
|----------|-----------|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulo |

### ✨ Features

- Performs basic arithmetic calculations
- Checks for division by zero
- Checks for modulo by zero
- Handles invalid operators

---

## 🎓 2. Marks & Grade System

A program that calculates a student's grade, result, and remark based on their marks.

### ✨ Features

- Adds bonus marks when applicable
- Determines grade using `if-else`
- Determines pass/fail using the **ternary operator**
- Displays a remark using the **switch statement**

### 📊 Grade System

| Marks | Grade |
|-------|-------|
| 90–100 | A |
| 70–89 | B |
| 50–69 | C |
| Below 50 | F |
